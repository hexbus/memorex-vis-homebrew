# Contributing

Contributions should preserve the distinction between:

```text
production ROM facts
inferences
513 reference cross-checks
VISENV implementation choices
```

Please do not commit BIOS ROM images, copyrighted SDK files, or 513 source files.  If you use these as a source to derive functionality, please state so.

When adding disassembly comments:

- keep one module per file
- use plain English comments
- mark uncertain labels as suspected
- do not claim a service contract unless it is verified
- keep raw ROM bytes unchanged in experiments
