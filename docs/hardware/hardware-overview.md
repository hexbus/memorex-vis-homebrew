# Hardware Overview

These notes are based on interior photos of an opened Memorex VIS unit.

## Visible system details

```text
Memorex Video Information System
Model 16-376
FCC ID G7W16-376
286-class CPU foundation
ROM-resident runtime
Mitsumi CRMC-F002L CD-ROM drive
TV-oriented analog outputs
```

## Visible rear I/O

```text
AUX IN
ANT/CABLE IN
TO TV RF out
composite video out
S-Video out
stereo audio out
```

## Development relevance

The hardware confirms that the VIS should be treated as a custom 286-based multimedia platform, not a generic VGA/Sound Blaster PC.
