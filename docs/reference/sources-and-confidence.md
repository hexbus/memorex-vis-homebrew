# Sources and Confidence

## Sources used

```text
production ROM analysis
REGISTER.EXE reversing notes
CONTROL.TAT / MAKETAT behavior
513 reference material used only for cross-checking
hardware photos of an opened VIS unit
publicly observable hardware markings
```

## Confidence terms

```text
High
  Directly visible in hardware, directly validated by tool output, or repeatedly confirmed by ROM analysis.

Medium
  Strongly supported by observed behavior but not yet fully byte-verified.

Low
  Plausible model awaiting hardware or ROM confirmation.
```

## Source hygiene

This repo does not copy proprietary 513 source files, BIOS ROMs, SDK files, or commercial title data.
