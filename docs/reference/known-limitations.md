# Known Limitations

## Not a full emulator

VISENV does not execute original ROM code or DOS binaries.

## CONTROL.TAT parser is conservative

The parser identifies known and observed fields but does not claim complete production validator parity.

## GBIOS services are stubs

The service families are represented, but exact register-level contracts still need verification.

## Video and input need hardware validation

Mode support, keyboard behavior, and hand-controller behavior need real VIS testing.

## Commercial title compatibility is not a goal yet

The focus is homebrew, not commercial title preservation or compatibility.
